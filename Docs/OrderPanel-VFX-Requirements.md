## ۱. پنل Orders (بخش جدید)

### ۱.۱ ظاهر

- بالای صفحه، وسط‌چین، بالای برد
- کارت افقی گوشه‌گرد: حاشیه قرمز ضخیم + پس‌زمینه کِرِم
- برچسب «Orders» روی لبه بالایی (قرمز، متن سفید)
- N اسلات کنار هم، جداشده با خط عمودی نازک
- تعداد اسلات‌ها **داینامیک** (۱ تا ۴)، چیدمان خودکار وسط‌چین

### ۱.۲ هر اسلات

- **آیکون**: Sprite رندرشده از مدل سودای همان رنگ (`Soda.SodaColor`)
- **شمارنده**: عدد باقی‌مانده، پایین-راست آیکون، فونت ضخیم تیره
- **حالت تکمیل**: عدد حذف → **تیک سبز** جایگزینش، آیکون کمی روشن/محو می‌شود

### ۱.۳ دیزاین در ادیتور (خواسته صریح)

روی `Board` یک لیست `Orders` اضافه می‌شود؛ هر ردیف:

```
[ SodaColor ▼ ]  [ تعداد: ⌷ ]  [ 🗑 ]
```

- `SodaColor` از همان enum پروژه: Red / Blue / Orange / Yellow / Green / Purple
- کنار هر ردیف، مربع رنگ متناظر برای شناسایی سریع
- دکمه‌های «افزودن سفارش» و «حذف»
- امکان جابه‌جایی ترتیب ردیف‌ها (ترتیب نمایش در پنل)
- **اعتبارسنجی در ادیتور**: هشدار اگر تعداد سفارش‌شده‌ی یک رنگ از تعداد قابل تولید در برد بیشتر باشد (لول غیرقابل‌حل)
- هشدار اگر لیست خالی باشد یا رنگ تکراری وجود داشته باشد
- نمایش پیش‌نمایش پنل در Scene view (اختیاری، اگر ساده بود)

### ۱.۴ رفتار در زمان اجرا

- شروع لول: پنل از لیست `Board.Orders` ساخته می‌شود
- هر جعبه‌ی پک‌شده: شمارنده‌ی همان رنگ ۱ واحد کم می‌شود
- جعبه‌ی رنگی که در سفارش نیست: افکت اجرا نمی‌شود (یا فقط `+1` بدون مقصد — قابل تنظیم)
- همه اسلات‌ها تیک خوردند → **برد لول**

## ۲. زنجیره افکت (فقط مراحل ۳ تا ۷)

نقطه شروع: بعد از اینکه سیستم فعلی جعبه را پک و برداشت.

| # | مرحله | جزئیات | مدت |
|---|-------|--------|-----|
| ۳ | **لیبل +1** | متن `+1` سفید ضخیم + آیکون کوچک نوشابه هم‌رنگ، از محل جعبه بالا می‌رود و fade out می‌شود | ~۰.۶s |
| ۴ | **دنباله درخشان** | نوار نورانی از محل جعبه تا اسلات سفارشِ همان رنگ پرتاب می‌شود | ~۰.۵s |
| ۵ | **برخورد** | فلاش/هاله زرد-سفید روی اسلات + کم شدن شمارنده | ~۰.۱s |
| ۶ | **پانچ آیکون** | آیکون سفارش کمی بالا می‌پرد و برمی‌گردد (scale + position punch) | ~۰.۳s |
| ۷ | **فروکش** | هاله محو، ذرات باقی‌مانده می‌ریزند و پاک می‌شوند | ~۰.۴s |

### ۲.۱ دنباله درخشان (هسته خواسته)

- نوار باریک و کشیده (comet/streak): نوک روشن‌تر، دنباله باریک‌شونده
- **ذرات ستاره‌ای ریز** در طول مسیر پخش و ریزش می‌کنند
- **رنگ نوار = رنگ همان نوشابه** (سبز برای سبز، آبی برای آبی، …) — نگاشت رنگ از `SodaColor`
- مسیر: از موقعیت جهانی جعبه تا موقعیت اسلات هدف — تبدیل World→Screen→Canvas
- مسیر کمی **منحنی** (Bezier)، نه خط صاف
- چند برخورد پشت‌سرهم بدون تداخل (Object Pooling)
- همه پارامترها (سرعت، انحنا، تعداد ذرات، ضخامت، مدت) از Inspector قابل تنظیم

### ۲.۲ هاله برخورد

- هاله زرد-طلایی شفاف و نرم، بزرگ‌تر از آیکون
- attack سریع، decay آرام
- در اوج هاله، آیکون یک لحظه سفید/اشباع می‌شود

### ۲.۳ تیک سبز نهایی

وقتی شمارنده‌ی یک سفارش به صفر رسید: عدد با یک pop کوچک محو می‌شود و **تیک سبز** با اسکیل از صفر همراه یک فلاش کوتاه ظاهر می‌شود.

## ۳. نقاط اتصال به کد موجود

| مورد | فایل | کار |
|------|------|-----|
| تشخیص پک شدن | `UniversalSodaTransferSystem.IsPacked` | انتشار رویداد `OnBoxPacked(SodaColor, Vector3 worldPos)` |
| رنگ | `Soda.SodaColor` | نگاشت enum → رنگ افکت + Sprite آیکون |
| جعبه | `Box.cs` | فراخوانی رویداد در پایان انیمیشن برداشت جعبه |
| دیزاین لول | `Board.cs` + `Editor/BoardEditor.cs` | لیست Orders + UI ادیتور + اعتبارسنجی |
| UI | `UIManager.cs` | میزبانی پنل Orders |
| برد | `WinPanel.cs` / `GameManager.cs` | شرط برد جدید |
| صدا | `SoundManager.cs` | صدای برخورد سفارش + صدای تیک نهایی |

### فایل‌های جدید (پیش‌بینی)

```
Assets/Scripts/Main Scripts/Orders/
    OrderDefinition.cs          // ساختار {SodaColor, count} + سریالایز
    OrderManager.cs             // وضعیت سفارش‌ها، رویدادها، شرط برد
    OrderPanelUI.cs             // ساخت و آپدیت پنل
    OrderSlotUI.cs              // یک اسلات: آیکون، شمارنده، تیک، پانچ
    OrderVfxDirector.cs         // زنجیره مراحل ۳ تا ۷
    SodaVisualLibrary.cs        // نگاشت SodaColor → Sprite + Color
    Editor/SodaIconBaker.cs     // ابزار رندر آفلاین آیکون‌ها
```
